# Bachelor_thesis_2026
"Design of an IoT device based on the microcontroller RP2040"

Abstract

This undergraduate thesis describes the design of an IoT (Internet of Things) device
based on the Raspberry Pi RP2040 microcontroller. The device is designed as a modular
platform that, via LoRa wireless technology, enables data reading from a temperature and
humidity sensor (DHT11), as well as from an additional external sensor connected via a
generic header, and controlling a bistable pulse relay via an integrated H-bridge driver.
The paper presents the theoretical foundations of the IoT system, the operating principles
of the RP2040 microcontroller, and the LoRa and LoRaWAN wireless protocols. The
hardware design process in EasyEDA software is also presented, including the creation of
an electrical diagram, component layout, PCB routing, and 3D visualization of the final
product. Each part of the design is supported by appropriate calculations and checks
based on the documentation of the components used, which confirms the correctness and
reliability of the proposed solution.
